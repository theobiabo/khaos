## One source, explicit boundaries

Khaos keeps entropy logic in Rust and treats every language binding as an adapter. That separation is the organizing principle for the workspace—not a claim about cryptographic readiness. Security review and a stable public API are still future work.

<dl class="boundary-list">
  <div>
    <dt>Rust core</dt>
    <dd>The planned `khaos-core` crate owns entropy primitives and policy.</dd>
  </div>
  <div>
    <dt>Node bridge</dt>
    <dd>The planned `khaos-napi` crate exposes a deliberately small NAPI-rs boundary.</dd>
  </div>
  <div>
    <dt>Typed surface</dt>
    <dd>The TypeScript package is reserved for JavaScript-facing types and ergonomics.</dd>
  </div>
</dl>

:::caution[Early workspace]
The repository is being scaffolded. Packages are not published and no production cryptographic guarantees are documented yet.
:::
