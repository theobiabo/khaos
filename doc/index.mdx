## Generate from changing signals

khaos explores the same idea behind Cloudflare’s Wall of Entropy at an accessible scale. Your application records a changing physical process, passes the bytes to khaos, and receives random output mixed with operating-system randomness.

<div class="install-list">
  <div class="install-row">
    <strong>Install the workspace</strong>
    <code>pnpm install</code>
  </div>
  <div class="install-row">
    <strong>Build the native module</strong>
    <code>pnpm --filter @khaos/native build</code>
  </div>
  <div class="install-row">

    <code>import &#123; generateBytes &#125; from "@khaos/typescript";</code>
  </div>

## One pipeline, visible boundaries

<div class="signal-line">
  raw bytes <b>→</b> unbias <b>→</b> BLAKE3 <b>→</b> keyed pool <b>→</b> ChaCha20 <b>→</b> rekey
</div>

<dl class="boundary-list">
  <div>
    <dt>Observe</dt>
    <dd>Capture bytes from a camera, microphone, sensor, recording, or another changing source.</dd>
  </div>
  <div>
    <dt>Unbias</dt>
    <dd>Discard matching bit pairs with the Von Neumann method.</dd>
  </div>
  <div>
    <dt>Extract</dt>
    <dd>Compress the surviving bits into a 32-byte BLAKE3 digest.</dd>
  </div>
  <div>
    <dt>Mix</dt>
    <dd>Combine the digest with a private pool initialized from operating-system randomness.</dd>
  </div>
  <div>
    <dt>Generate</dt>
    <dd>Expand the pool state with ChaCha20, return the requested bytes, and rekey.</dd>
  </div>
</dl>

## Start with TypeScript

```typescript
import { generateBytes, inspectEntropy } from "@khaos/typescript";

const sample = new Uint8Array([0b01100110, 0b10011001]);
const report = inspectEntropy(sample);
const bytes = generateBytes(sample, 32);

console.log(report);
console.log(Buffer.from(bytes).toString("hex"));
```

The TypeScript package calls the NAPI-rs binding, which delegates all entropy processing to the Rust core. The binding does not maintain a second cryptographic implementation.
